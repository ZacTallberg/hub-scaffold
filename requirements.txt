# hub-scaffold runtime dependencies.
#
# hub_core/ is PURE STDLIB — zero dependencies — and runs under Python 3.10+.
# Only the Django ADAPTER (adapters/django/) and the example/ site need Django.
#
# Django 5.2 is the supported LTS floor (Python 3.10+); Django 6.0 is supported on Python 3.12+.
# The upper bound prevents a future feature series from silently redefining the scaffold contract.
# Pin and promptly patch your chosen series once you mount the adapter into an application.
Django>=5.2,<6.1

# OPTIONAL ASGI process server -- install one in the deployment environment that serves the Hub's
# long-lived realtime event stream. Uvicorn is the simplest reference path; Hypercorn and Daphne
# are equally valid ASGI choices. The scaffold does not force a process-server dependency on every
# adopter because the production host should own and pin that operational choice:
#
#   python -m pip install uvicorn
#   # or: python -m pip install hypercorn
#   # or: python -m pip install daphne
#
# From the directory containing manage.py, point it at <project>.asgi:application. Django's WSGI
# development runserver remains a compatibility preview, not the operating shape for long-lived SSE.

# Strict-mode dereferencing of submitted evidence relies only on urllib from the stdlib — no
# `requests`. The Hub page inlines its small frontend kit, so the adapter adds no static-file serving
# dependency. Neither tracked nor strict mode requires a `verification_command`.

# OPTIONAL — deliberately NOT installed by default, so uncomment it if you want a signed card:
#
#   cryptography>=42
#
# Only the A2A agent card (/.well-known/agent-card.json) uses it, and only to SIGN itself: the card
# is an ES256 JWS so a consumer can verify it without trusting the transport. Without the library
# the card is still served, unsigned, and says so in its own `signatures` field. A discovery
# document that 500s because it could not sign hides the whole hub from every standard client,
# which is a worse failure than an unsigned card. Nothing else in the scaffold imports it.

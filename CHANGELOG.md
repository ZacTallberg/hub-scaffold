# Changelog

**This repository is GENERATED.** Since 2026-08-07 the scaffold is a scrubbed export of the
upstream canonical hub template, regenerated by an agent whenever the template changes — never
committed to directly. An improvement made here would be lost on the next export and, worse,
would fork the engine again (that fork is exactly what the 2026-08-07 consolidation resolved).
Upstream the change to the canonical template, then re-export. The export gates
(`tools/scrub_check.sh --selftest`, `tools/selftest.sh`) belong to this layer and stay here.

This file records changes to the scaffold itself. Project changelogs generated from adopted Hub
deploy events are a different artifact (`hub_core.projections.render_changelog_md`).
